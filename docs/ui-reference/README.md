# Legacy interface references

These Ambient Weather interface captures are design references, not screenshots of Midway Weather. See [the current application tour](../screenshots/README.md) for authentic Midway Weather desktop, mobile, and administration views.

- `ambient-dashboard-1.png`: outdoor temperature, wind, rainfall, and pressure layout. The original map, markers, geographic labels, browser URL, and station identity have been removed.
- `ambient-dashboard-2.png`: humidity, UV, solar, indoor conditions, batteries, forecast, and sun/moon layout. Browser chrome and station identity have been removed.
- `ambient-dashboard-3.png`: the original cropped forecast reference, which has no station URL or map.

The first two images were privacy-edited with an image-editing model and visually checked for removed identifiers and retained layout/readings. They are reference illustrations after redaction, not pixel-exact captures or evidence of current weather. The map omission in the first image is deliberate; no substitute location or weather data was introduced.

Third-party interfaces, branding, and data retain their respective rights; see [third-party notices](../../THIRD_PARTY_NOTICES.md). This public repository starts with these sanitized images and does not include the original captures or their earlier Git history.
